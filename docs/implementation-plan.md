# macOS 字符播放器中文实施计划

目标：在本机提供可双击启动、可从终端运行的离线原生播放器。
架构：Swift + AVFoundation + Darwin；系统 gzip 解压 Assets 中的数据。
设计：见 design.md。执行方式：当前会话直接实现。

约束：不读取秘密文件；不创建或运行单元测试；全部完成后统一验证；不复制或运行关机脚本；不联网获取素材；不修改原 Windows 项目。
