# 雨爱 macOS 终端播放器设计

## 目标
在 `/Users/checkmate/Documents/RainASCII` 新建独立项目，实现 Downloads/雨爱 中 Windows 终端动画的 macOS 版本。Windows 源目录保持原样。用户可以双击 `雨爱.command`，或在已打开的终端中运行入口，播放现有约 110 秒的黑白字符动画与音轨。

## 首版功能
- 保留约 3 秒乱码扫屏、进度提示与渐隐开场。
- 复用现有 `frames.bin.gz` 与 `audio.wav`，按数据头帧率播放。
- 按终端尺寸居中、保持画面比例；调整窗口大小后重新排版。
- 支持 Q、Esc、Ctrl+C 退出；退出或报错时停止音频并恢复光标和终端输入状态。
- 支持静音和跳过开场的命令行选项。
- 播放滞后时跳帧，使画面跟随音轨播放时间。
- 提供可双击入口、构建脚本、源代码与中文 README。

## 实现选择（由实现者提出）
使用 Swift、Darwin 和 AVFoundation 实现原生命令行播放器；使用系统 gzip 解压现有帧数据，无需网络、Python 或第三方运行库。开发构建需要 Apple Command Line Tools；本机生成的可执行文件供本机运行，不承诺跨架构或经过公证的分发。首版交付本机可运行程序。

使用 ANSI 转义序列和备用屏幕，在 Terminal 中绘制 ASCII 字符。终端字符宽高比默认 0.5，提供可覆盖参数，因为不同字体的字符比例可能不同。保留末行避免滚屏。
